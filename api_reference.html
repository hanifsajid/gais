class gais.OpenAICompatibleProvider(provider_name: str, model: str, api_key: str, base_url: str | None = None)[source]

Bases: BaseProvider

Base wrapper for OpenAI-compatible LLM providers with optional structured parsing.

Supports both OpenAI’s native parsing (if available) or a fallback structured parser using StructuredOutput.
